1. Namecheap + Resend DNS

Verify twisted23.com in Resend and add these records in Namecheap → Advanced DNS:

  • DKIM (TXT): Host resend._domainkey
  • Return-Path SPF (TXT): Host send → v=spf1 include:amazonses.com ~all
  • Return-Path MX (MX): Host send → Priority 10 (from Resend)
  • DMARC (TXT): Host _dmarc → v=DMARC1; p=none; rua=mailto:media@twisted23.com
