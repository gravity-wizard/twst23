1. Namecheap + Resend DNS

Verify twisted23.com in Resend and add these records in Namecheap → Advanced DNS:

  • DKIM (TXT): Host resend._domainkey
  • Return-Path SPF (TXT): Host send → v=spf1 include:amazonses.com ~all
  • Return-Path MX (MX): Host send → Priority 10 (from Resend)
  • DMARC (TXT): Host _dmarc → v=DMARC1; p=none; rua=mailto:media@twisted23.com

2. Replies Without Exposing botchee@icloud.com

Keep Namecheap Email Forwarding (media@twisted23.com → botchee@icloud.com) for inbound, and configure Apple Mail's outgoing SMTP to smtp.resend.com (Port 465, SSL, user resend, password = API key).

3. Resend Webhook URL

Point Resend Webhooks to:

https://twisted23.com/crm/api/webhooks/resend

Events: email.sent, email.delivered, email.bounced, email.opened.
